  Wenn der Grund zu unruhig ist, löst sich die Figur auf. Klassiker: Text auf einem Foto (siehe Prinzip Farbe und Lesbarkeit). Weißer Text auf einem unruhigen Untergrund verschwindet stellenweise. Lösung: Der Text bekommt einen eigenen ruhigen Grund, eine Fläche, einen Verlauf oder eine ruhige Bildstelle.

  Bewusst gebrochen wird die Regel, wenn das Kippen der Witz ist: Logos, Plakate, Anzeigen (siehe Carlsberg im Phänomen Kippfiguren). Im Interface ist das fast nie eine gute Idee.
